IPTVZB

组播源

组播源 API 抓取 + 有效性检测 + 按模板分组，每日 06:00 / 12:00 / 18:00 更新。

✓ 巡检 https://zzf.new.tg/checked/live.m3u

最近更新：查询中… 每天 3 次

标着 ✓ 巡检 的是每小时自动复检过的版本：连续两次探测失败的线路会被剔除，恢复正常的线路下一轮自动回来；其余 M3U 是每天全量生成的原始列表。

用法：把上面的 M3U 链接粘到播放器的「订阅 / 网络列表」里即可，支持 TiviMate、影视仓、PotPlayer、Kodi 等；TXT 格式供只接受「分类,频道,地址」列表的软件使用。

订阅链接直接走各自的域名（GitHub Pages），没有 CDN 缓存，文件更新后立即生效；标「备用」的是 jsDelivr 镜像，域名被网络干扰时换用那条即可。

注：tingbao.cc.cd 在部分国内网络会被重置（DNS 能解析但连接被断），遇到打不开就用备用链接，或直接用 zzf.new.tg 上的 IPTVZB 列表。

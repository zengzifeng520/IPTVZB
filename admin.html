仅站长使用

本站是纯静态站，没有自建服务端。后台通过 GitHub 接口直接读写仓库里的 data/users.json，所以需要一个有本仓库 Contents 读写 权限的 Personal Access Token。

Token 只保存在你这台浏览器，不会写进仓库、不会上传到任何地方。 建议用 Fine-grained token，只勾选本仓库的 Contents: Read and write。

说明

  • 保存后仓库会触发 Actions 重建订阅，约 1 分钟生效，用户刷新页面即可看到新状态。
  • 改到期日：直接改日期框，或点「+30 天 / +90 天」在原到期日上顺延。
  • 删除：用户从 users.json 移除，他的订阅目录会被删掉，链接变成 404。
  • 到期：文件不会被删除，而是改写成空列表，播放器刷新后就是 0 个频道。
  • 赞助码是用户在本机自动生成的 12 位码，必须由用户提供给你后才能加进来。

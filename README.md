# 光影直播 · 全国直播源按地区取用

把公开采集到的 IPTV 组播地址，经过探测、去重、按地区归类后，做成一个「手机号注册 → 查看本省频道 → 扫码开通全部地区」的订阅站。

纯静态站点，没有后端，直接跑在 GitHub Pages 上。

---

## 页面

| 页面 | 作用 |
|---|---|
| `index.html` | 首页：账号状态条 + 统计 + 11 个地区卡片（未登录/未开通的加锁） |
| `login.html` | 手机号 + 密码注册登录，注册时锁定 1 个地区 |
| `account.html` | 账户中心：套餐状态、扫码付款（¥15）、会员订阅列表 |
| `region.html` | 频道页：按地区切换、频道地址逐条复制、会员专属订阅地址 |

体验版（刚注册）：只能查看锁定地区的频道地址，看不到订阅文件。
会员（扫码开通）：全部 11 个地区 + 全量 M3U 订阅 + 分地区订阅。

## 账号与付费

没有服务端，所以这套体系是**纯前端 + 本地存储**：

- 注册：手机号 + 密码，密码用加盐 SHA-256 哈希后存 `localStorage`，不保存明文
- 记住账号：登录页可勾选「记住账号密码」，下次打开自动填好；只勾账号则只记手机号
- 退出：首页、频道页、账户页右上角都有退出入口，退出只清会话，保留已记住的账号
- 地区锁定：注册时选定的地区写进账号记录，之后不可更改
- 付费：展示微信收款码，用户付款后点「我已完成付款」即在本地标记为会员
- 套餐（4 档，续费按所选档位在原到期日上累加，过期后从当天重新起算）：

  | 套餐 | 价格 | 时长 |
  |---|---|---|
  | 体验版 | ￥2 | 1 天 |
  | 月付 | ￥8 | 30 天 |
  | 季付 | ￥20 | 90 天 |
  | 年付 | ￥80 | 365 天 |

- 过期行为：到期后账号自动降级为免费版（只剩注册时锁定的 1 个地区），
  订阅列表与订阅地址全部停止发放，账户页与首页显示「已过期」并引导续费。

**必须知道的局限**（纯静态站的固有限制，不是实现遗漏）：

1. **不做付款核验**。个人微信收款码没有到账回调，无法知道谁付了钱。当前实现是「用户点一下就开通」，等于信任用户。想真正核验，需要微信商户号 + 支付回调接口 + 一台公网后端。
2. **账号只存在本机浏览器**。换设备或清缓存后需要重新注册、重新开通。需要跨设备就得接后端（云数据库或自建 API）。
3. **页面权限是 UI 层控制**。`data/proxy.json` 和 `data/sub/*.m3u` 是公开文件，懂技术的人可以直接请求。要真正防止绕过，必须把数据放到需要鉴权的后端后面。
4. **已拿到的订阅地址不会因过期而失效**。订阅文件是静态资源，一旦被复制进播放器就一直能下载，直到文件被删除。过期只会让页面不再显示地址，管不住手里的旧 URL。要做到「过期即断」，需要后端按会员校验，或定期轮换订阅路径。

## 数据管线

```
公开源 m3u / Quake 测绘地址
        │
        ▼
  udpxy.py          探测 /status，只留可达的中转服务器（存活 33 台）
        │
        ▼
  shushu_enrich.py  存活主机 → 解析接口，让服务器自报全量频道
        │            （13 台可解析 / 2461 条地址）
        ▼
  regions.py        IP 归属地（ip-api 批量，缓存 30 天）→ 按省份聚合
        │
        ▼
  proxy.json        566 频道 / 4450 条地址
  regions.json      11 个地区
        │
        ▼
  subs.py           all.m3u（全量）+ region/<KEY>.m3u（分地区）+ index.json
```

按地区拆分的原因：udpxy 中转服务器基本只在本省运营商网内可达，跨省地址大多连不上。

## 日常运行

```bash
cd spider
python run.py              # 采集 + 探测公开源
python shushu_enrich.py    # 存活主机喂解析接口
python shushu_import.py    # 转 m3u 合并
python udpxy.py            # 合并两个源并汇聚
python regions.py          # 生成地区分组
python subs.py             # 生成订阅文件
```

GitHub Actions 每天北京时间 03:20 自动跑一遍并提交数据（`.github/workflows/site-data.yml`）。

## 改套餐

`assets/js/auth.js` 顶部的 `PLANS` 一处改完即可（价格、天数、标签都在这）：

```js
var PLANS = [
  { key: "day",     name: "体验版", price: 2,  days: 1,   unit: "天", tag: "先试一天" },
  { key: "month",   name: "月付",   price: 8,  days: 30,  unit: "天", tag: "最灵活" },
  { key: "quarter", name: "季付",   price: 20, days: 90,  unit: "天", tag: "更划算" },
  { key: "year",    name: "年付",   price: 80, days: 365, unit: "天", tag: "最超值", hot: true },
];
var DEFAULT_PLAN = "month";   // 默认选中的档位
```

页面上所有价格、天数、按钮文案都由这份配置渲染，不用再改 HTML。
